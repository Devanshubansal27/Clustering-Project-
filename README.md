# **A Data-Driven Approach to Fund Allocation for Help International NGO** 🌍📊

## **Introduction**  

This project focuses on **clustering countries** based on **socio-economic and health indicators** to help **Help International**, an NGO, **allocate funds more effectively**. By analyzing key development metrics, we ensure that **countries with the greatest need** receive more financial aid.  

---

## **Objective** 🎯  

The goal of this project is to:  
✔ **Segment countries into clusters** based on health, education, and economic indicators.  
✔ **Identify high-need regions** to prioritize for funding.  
✔ **Develop a data-driven strategy** for fair and efficient fund allocation.  

---

## **Methodology** 🔬  

1. **Data Collection** – Obtained socio-economic and health-related data for different countries.  
2. **Data Preprocessing** – Cleaned, normalized, and handled missing values in the dataset.  
3. **Feature Selection** – Identified key factors affecting a country’s development.  
4. **Clustering Algorithm** – Applied **K-Means Clustering** to segment countries into different groups.  
5. **Analysis & Insights** – Interpreted clusters to recommend funding priorities.  

---

## **Technologies Used** 🛠  

- **Python** – Primary programming language  
- **Pandas & NumPy** – Data manipulation and analysis  
- **Matplotlib & Seaborn** – Data visualization  
- **Scikit-learn** – K-Means clustering and preprocessing  
- **Jupyter Notebook** – Development environment
